数据与隐私说明

浏览器采集

采集助手只在用户点击“采集当前页”后读取当前小红书笔记页面中已经显示的标题、正文、作者、发布时间、互动数据和链接。扩展不会读取账号 Cookie，也不会自动遍历或批量抓取页面。

本地数据

复核状态、集合与报告保存在当前浏览器的 localStorage。清除站点数据或更换设备后不会自动恢复，请使用 CSV 或 Word 导出保留结果。

DeepSeek

API Key 只保存在当前标签页会话中，并随分析请求发往本服务端，再由服务端转发到 DeepSeek。服务端不保存 API Key。提交分析时，已确认样本和报告统计会发送给 DeepSeek。

演示范围

本站为独立作品集项目，默认数据均为虚构示例，不代表任何品牌的真实经营表现。互动数据只描述采集时点的公开页面状态，不等同于销量、份额或消费偏好。
